## Engineering Focus

I build **open-source systems and developer-facing infrastructure**: software that coordinates agents, understands repositories, schedules compute, models infrastructure, survives degraded networks, and explores how damaged data can be reconstructed without hiding uncertainty.

My current work spans:

- **Storage & recovery research** — damaged-image analysis, evidence fusion, reconstruction constraints, provenance, uncertainty and reproducible corruption benchmarks
- **Resilient public infrastructure** — offline-first communication, trusted alerts, mesh synchronization, privacy-aware emergency coordination
- **AI infrastructure** — agent orchestration, tool permissions, memory, task graphs, model/provider interoperability
- **Developer tooling** — repository intelligence, static analysis, migration planning, Git automation, CI and deployment workflows
- **Distributed systems** — worker scheduling, trusted compute, capability matching, deterministic convergence, failover-oriented architecture
- **Backend & control planes** — APIs, schedulers, state models, validation, CLI systems and service boundaries
- **Polyglot systems engineering** — C++23/C++20, Go, Kotlin/JVM, Java, TypeScript, Python, JavaScript, SQL and shell tooling
- **Open interoperability** — schemas, protocol adapters, explicit cross-runtime contracts, MCP/A2A-style concepts

## Flagship Systems

### RESURGE BLACKLAB — Proof-Carrying Data Recovery Research

[`nova-spectre777/resurge-blacklab`](https://github.com/nova-spectre777/resurge-blacklab)

An experimental, read-only-first storage-recovery research platform built around **MERA-ΩX PRIME**: counterfactual candidate reconstruction, contradiction-first elimination, recovery entropy, active acquisition ranking, multi-clone fusion, immutable overlays and digest-bound recovery certificates.

**Verified stack:** `C++23 engine` · `Go control plane` · `Python corruption lab` · `TypeScript recovery studio` · `Java 21 evidence plugins`

**Research source tracks:** `CUDA C++` · `Zig` · `Julia` · `Lean 4` · `SystemVerilog` — included as experimental interfaces, not claimed verified in the v0.1 build environment.

RESURGE deliberately distinguishes `PHYSICAL`, `PROVEN`, `CORROBORATED`, `INFERRED`, `AMBIGUOUS` and `LOST` regions instead of presenting every plausible reconstruction as original data.

### CIVICMESH — Offline-First Public Resilience Network

[`nova-spectre777/civicmesh-platform`](https://github.com/nova-spectre777/civicmesh-platform)

An experimental public-good platform for signed emergency alerts, local mesh synchronization, shelter/resource discovery, help coordination and network-partition recovery when normal connectivity degrades.

**Architecture:** `Go gateway + Ed25519 trust` · `Kotlin offline client` · `C++20 edge relay` · `TypeScript PWA` · `Python disaster-network simulator` · `JSON protocol contracts`

CIVICMESH deliberately separates official signed alerts from community observations, uses coarse-location and expiry primitives for privacy, and treats real-world deployment as something that requires authority partnerships, audits and field testing—not a README claim.

### FORGE — Polyglot Repository Modernization Engine

[`nova-spectre777/forge-platform`](https://github.com/nova-spectre777/forge-platform)

A multi-language modernization control plane that separates repository analysis, migration planning, dependency ordering, worker scheduling and operator visualization.

**Architecture:** `C++20 scanner` → `Python planner` → `Go control plane` → `TypeScript console`, with a `Java 21 plugin SDK` for JVM/framework modernization checks.

FORGE is designed around inspectable JSON contracts, migration DAGs, risk scoring, capability-scoped workers and verification-first change planning rather than blind code rewriting.
