My current work spans:

## Flagship Systems

### CIVICMESH — Offline-First Public Resilience Network

[`nova-spectre777/civicmesh-platform`](https://github.com/nova-spectre777/civicmesh-platform)

An experimental public-good platform for signed emergency alerts, local mesh synchronization, shelter/resource discovery, help coordination and network-partition recovery when normal connectivity degrades.

**Architecture:** `Go gateway + Ed25519 trust` · `Kotlin offline client` · `C++20 edge relay` · `TypeScript PWA` · `Python disaster-network simulator` · `JSON protocol contracts`

CIVICMESH deliberately separates official signed alerts from community observations, uses coarse-location and expiry primitives for privacy, and treats real-world deployment as something that requires authority partnerships, audits and field testing—not a README claim.

### FORGE — Polyglot Repository Modernization Engine

[`nova-spectre777/forge-platform`](https://github.com/nova-spectre777/forge-platform)

A multi-language modernization control plane that separates repository analysis, migration planning, dependency ordering, worker scheduling and operator visualization.

**Architecture:** `C++20 scanner` → `Python planner` → `Go control plane` → `TypeScript console`, with a `Java 21 plugin SDK` for JVM/framework modernization checks.

FORGE is designed around inspectable JSON contracts, migration DAGs, risk scoring, capability-scoped workers and verification-first change planning rather than blind code rewriting.
